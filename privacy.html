Privacy Policy

Last updated: 2 November 2026

Lemo Uploader is a personal tool that runs only on its owner's computer.

What it accesses

It asks for one Google permission, youtube.upload, so it can upload videos and thumbnails to the signed-in YouTube channel. It reads no other Google user data.

What it stores

The OAuth token is saved in a local file on the owner's computer. No data is sent to any server other than Google's APIs. Nothing is shared, sold or used for advertising.

Revoking access

You can remove access at any time at myaccount.google.com/permissions.

Lemo Uploader uses YouTube API Services. See the Google Privacy Policy.
